# Photodiode-MATLAB
MATLAB program to calculate photodiode parameters and plot V-I and P-V characteristics
Photodiode Characteristics Using MATLAB

Project Overview

This project uses MATLAB to calculate the electrical characteristics of a photodiode and analyze its performance.

Objectives

- Calculate Maximum Power (Pmax).
- Calculate Maximum Voltage (Vmax).
- Calculate Maximum Current (Imax).
- Calculate Fill Factor (FF).
- Calculate Efficiency.
- Plot V-I and P-V characteristics.

Software Used

- MATLAB

Input Values

- Open Circuit Voltage (Voc) = 8 V
- Short Circuit Current (Isc) = 10 mA
- Input Power (Pin) = 80 mW

Output Results

- Maximum Power = 20 mW
- Maximum Voltage = 4 V
- Maximum Current = 5 mA
- Fill Factor = 0.25
- Efficiency = 25%

Graphs

The project includes:

1. V-I Characteristics
2. P-V Characteristics
